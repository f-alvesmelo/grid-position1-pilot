# Next Steps

Command: `/analysis`. Concrete, ordered next actions — distinguishing what the researcher must do (real-world evidence gathering) from what the agent can do (repository/documentation work).

## For the Researcher (requires real-world evidence gathering)

1. **Pick 2–3 real pilot episodes** from [[Data Sources]] — e.g., one Colombia conflict event, one Iraq conflict event (2014–2015 peak period), one Burundi disaster event — to hand-code as a first reliability test.
2. **Gather documentary evidence** for each: political/coalition composition at national and local levels around the episode's onset; humanitarian-assistance policy and practice for that episode. This is the evidence base [[Coding Protocol]] requires and that no file currently on hand supplies.
3. **Run the pilot coding** per [[Coding Protocol]] Steps 1–8, recording confidence per [[Evidence Standards]].
4. **Decide the aggregation and derivation thresholds** the two memos left open: exact evidence thresholds for `alignment_structure` categories, and the `authority_locus` derivation rule when the four indicators disagree.

## For the Agent (repository/documentation work — can proceed without new evidence)

1. `/reproduce` — build `07_Reproducibility/` documenting the workflow from project → variables → data → coding → analysis → output, and the data provenance chain now that real data is on hand.
2. `/vault` — verify Obsidian navigation/links across all files built so far.
3. `/github` — write the README once the above are stable.
4. Extend [[Data Sources]] coverage: process the remaining unread portions of the larger disaster CSVs (Colombia's 1,059 events, Burundi's 724 events) if a fuller descriptive picture of disaster-driven episodes is wanted before pilot coding begins.

## Explicit Non-Goal

Do **not** attempt to infer `response_de_jure`/`response_de_facto` or `align_*` values from the displacement magnitude data alone, no matter how tempting a pattern looks in [[Comparative Analysis]] — that would fabricate exactly the coding this project's entire methodological apparatus ([[Coding Protocol]], [[Evidence Standards]]) was built to do carefully and evidentially.
