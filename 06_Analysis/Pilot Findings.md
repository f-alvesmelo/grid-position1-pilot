# Pilot Findings

Command: `/analysis`. Per AGENT.md §26 and §2: the agent must not "convert expectations into findings" or fabricate results. This file states, as plainly as possible, what has and has not been found.

## On the Actual Research Question (H1–H3): No Findings

**There are no findings on H1, H2, or H3.** These hypotheses concern the relationship between political alignment configuration, institutional authority locus, and government response (protection/repression, de jure/de facto). None of the three variables required to test them have been coded for any observation:

- `align_NG_local`, `align_NG_IDP`, `align_local_IDP`, `alignment_configuration`, `alignment_structure` — **0 observations coded**.
- `authority_formal`, `authority_budget`, `authority_admin`, `authority_actual`, `authority_locus` — **0 observations coded**.
- `response_de_jure`, `response_de_facto`, `response_consistency` — **0 observations coded**.

This is not an oversight to be filled in by inference from the displacement data — per [[Data Sources]], the real data received (IDMC/World Bank) contains no political, administrative, or policy-response information at all. Coding these variables requires a separate evidentiary pass against documentary/political sources per [[Coding Protocol]], which has not been undertaken.

## On Displacement Magnitude: Real Descriptive Results Exist

[[Descriptive Analysis]] and [[Comparative Analysis]] report real, computed findings about **displacement magnitude and trajectory** for Burundi, Iraq, and Colombia, 2008–2025 (e.g., Colombia's conflict-driven IDP stock more than doubling over the period, while Burundi's and Iraq's each declined substantially). These are genuine empirical results, properly sourced to IDMC, and can be cited as such.

**They are not evidence for or against H1–H3.** A declining or rising displacement stock is an outcome of the displacement process itself (conflict dynamics, returns, resettlement), not a direct measure of protective or repressive government response. Treating displacement-trend differences as if they were response-profile differences would be exactly the unsupported inferential leap the non-fabrication rule and AGENT.md §15 ("do not infer causal effects merely from descriptive associations") are meant to prevent.

## What Would Be Needed for Real Findings on H1–H3

1. Select a small number of real, dated displacement episodes from [[Data Sources]] (e.g., a specific conflict-category IDMC event in Colombia, Iraq, or Burundi).
2. For each selected episode, gather real documentary evidence — political/coalition composition, electoral results, government policy documents, humanitarian assistance records — following [[Coding Protocol]] Steps 1–7.
3. Code the alignment, authority, and response variables per [[Data Dictionary]], recording evidence and confidence per [[Evidence Standards]].
4. Only then would a genuine (if small-N, illustrative) test of H1–H3 be possible — and even then, per AGENT.md §15, any such pilot-scale result should be labeled **ILLUSTRATIVE ANALYSIS**, not a general finding.

This has not been done in this session because it requires real-world political/administrative research (e.g., identifying an actual government's actual humanitarian-assistance policy and practice for a specific real episode) that was not supplied and should not be guessed at.
