# Observable Implications

Command: `/theory`. Distills [[Mechanisms]] into a single table of what should be observed in the data if each hypothesis holds, restricted to the pilot scope (humanitarian assistance domain). Candidate tests marked AGENT PROPOSAL are not yet run — no results are claimed.

## Summary Table

| Hypothesis | If true, we should observe... | Domain scope | Status |
|---|---|---|---|
| H1 (shared alignment → protection) | Cases with `alignment_structure` = shared alignment show higher rates of `response_de_jure`/`response_de_facto` = "consistent protection" than cases coded predominantly aligned, fragmented, or shared opposition. | Pilot: humanitarian assistance | [EVIDENCE NEEDED] |
| H2 (fragmented alignment → heterogeneous response) | Cases with `alignment_structure` = fragmented show higher rates of de jure/de facto divergence ("protective-inconsistent" / "repressive-inconsistent") than cases coded shared alignment or shared opposition. | Pilot: humanitarian assistance | [EVIDENCE NEEDED] |
| H3 (`authority_locus` moderates) | For `authority_locus` = L, `align_local_IDP` predicts response better than `align_NG_IDP`; reverse for `authority_locus` = N. `authority_locus` = D (delegated) mechanism is unsettled (see [[Mechanisms]]). | Pilot: humanitarian assistance | [EVIDENCE NEEDED]; `authority_locus` is now a defined, codeable variable but no cases coded yet |

## Falsification Conditions (AGENT PROPOSAL — for researcher review)

- H1 would be undermined if aligned cases show **no more** consistent protection than non-aligned cases in humanitarian assistance.
- H2 would be undermined if fragmented cases show **uniform** (not heterogeneous) responses — e.g., uniformly repressive regardless of which dyad is fragmented.
- H3 would be undermined if the *same* dyad (e.g., always national–displaced-population) predicts response regardless of which actor formally holds authority over the domain.

These falsification conditions are the agent's proposed operational readings of "supported" vs. "not supported" — they have not been confirmed by the researcher and should be reviewed before use in actual analysis.

## Scope Caveat

All observable implications above are scoped to the **pilot domain (humanitarian assistance)** and to whatever country/case sample is actually coded during the pilot. They do not yet extend to the full cross-national GRID sample (1989–latest year, all countries) or to other domains, per [[Scope & Limitations]].
